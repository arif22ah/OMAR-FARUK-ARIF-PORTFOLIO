# Omar Faruk Arif — Data Scientist Portfolio (Next.js + TypeScript + Tailwind CSS)

Production-ready modular portfolio web application for **Omar Faruk Arif**, Data Scientist and B.Sc. in Computer Science & Engineering (Major: Data Science) Graduate from **United International University (UIU)**.

## Quick Start (Windows Command Prompt / Double-Click)
1. Extract this ZIP archive to any folder (e.g., `C:\Users\arif\Omar-Faruk-Arif-portfolio`).
2. Double-click **`run_local.bat`** (or run `npm install && npm run dev` in `cmd`).
3. Open `http://localhost:3000` in your browser.

## Also Included: Standalone Separated Vanilla Version (`/standalone-vanilla`)
If you also want to host directly on GitHub Pages without Node.js build steps, the `standalone-vanilla/` folder contains the cleanly separated `index.html`, `styles.css`, and `app.js` files.
